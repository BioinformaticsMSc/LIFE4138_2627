Here, you will find all the necessary materials for this module.

To access the materials from this repository, run the following on your unix terminals:

```console
git clone https://www.github.com/BioinformaticsMSc/LIFE4138_2627
cd LIFE4138
conda env create -f lectures.yml
conda activate lectures
```
Then, assuming this is successful, run this from the LIFE4138 folder:

```console
jupyter lab
```
